# ISC26 Virtual Student Cluster Competition - ASCOT5

This repository contains the results obtained from running the [ASCOT5](https://ascot4fusion.github.io/ascot5/) (Accelerated Simulation of Charged Particle Orbits in Tori) software on the *IRIS* (University of Luxembourg)
and *ROMEO* (University of Reims Champagne-Ardenne) supercomputers. This was one of the challenges set by the HPC-AI Advisory Council and ISC committee for the **ISC26 Virtual Student Cluster Competition**. The challenge
involved experimenting with, optimising and investigating the scalability of ASCOT5 via parameter tuning and data analysis. Use of CPU and GPU clusters (IRIS and ROMEO respectively) is also detailed.

## Runs and Builds
The optimal (giving the lowest runtime) build and run scripts in Bash can be found in the `IRIS` and `ROMEO` directories.

## Presentation and Analysis
The full analysis and presentation can be found in the `ANALYSIS` directory.
